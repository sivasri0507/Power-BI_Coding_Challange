# Hospital Billing & Patient Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze hospital billing data, patient demographics, and financial KPIs.

## Key Features
- **Data Modeling:** Established a 1:N relationship between Patients and Billing tables.
- **DAX Calculations:** Implemented YTD Revenue, MoM Growth %, Average Bill Amount, and Patient Ranking.
- **Interactive Visuals:** Includes Matrix with Data Bars, Treemaps, Line Charts, and Slicers.
- **User Navigation:** Integrated Bookmarks and a Reset Filter button for smooth navigation.
